# 91. 폐쇄망 확인표 — 은행 개발 DB 로 견본 4화면 확인

> 이 클라우드에서는 Oracle 에 붙을 수 없어 **SQL 실행 확인은 폐쇄망에서만** 된다(설계 §11). 이 표를 채우면 확인이 끝난다.
> 결과 칸 표기: `OK` / `NG(증상)` / `-`(해당 없음). NG 는 화면 문구·응답코드·서버 로그 첫 줄을 그대로 적는다.
> 개인번호·계정·IP 는 적지 않는다(nh-atms `CLAUDE.md` 원본 자료 규칙).

## 3. 화면별 확인

- 권한 칸: 내 권한코드(`TB_SCR_AUTH.AUTH`)로 버튼이 흐려지는지 + 서버가 403 `SYS_403` 을 주는지. 다른 권한코드로 바꿔 볼 수 있으면 A·T·L 각각 적는다(시드 플래그: `db/seed/README.md`).
- 감사 칸: 등록·수정한 행의 `CRT_DTM`·`CRT_CMENO`·`LSCHG_DTM`·`LS_CMENO` 를 DB 에서 조회해 본다(등록 4개, 수정은 `LSCHG_DTM`·`LS_CMENO` 만 바뀜, 개인번호 = 고정 사용자).
