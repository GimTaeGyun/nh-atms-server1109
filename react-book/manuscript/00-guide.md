# 이 책을 읽는 방법

이 책은 4부 14장입니다. 앞 장에서 배운 것만으로 다음 장을 읽도록 썼으니 차례대로 읽으세요.

| 부 | 무엇을 배우나 | 읽고 나면 |
|---|---|---|
| **1부**&nbsp;웹&nbsp;화면의&nbsp;기초&nbsp;체력<br>1~4장 | 웹 화면이 뜨는 과정, HTML과 CSS, 자바스크립트, 타입스크립트 | 소스 파일을 열어도 기호가 낯설지 않습니다 |
| **2부**&nbsp;리액트&nbsp;기본기<br>5~8장 | 화면을 부품으로 나누고, 값을 건네고, 값이 바뀌면 화면이 따라 바뀌게 하는 법 | 화면 부품 하나를 읽고 설명합니다 |
| **3부**&nbsp;우리&nbsp;프로젝트&nbsp;읽기<br>9~13장 | 폴더와 파일, 화면 이동, 함께 쓰는 값, 서버와 주고받기, 공통 부품 | 공지사항 화면의 소스가 읽힙니다 |
| **4부**&nbsp;실전,&nbsp;화면&nbsp;하나&nbsp;만들기<br>14장 | 공지사항 화면을 빈 파일부터 따라 만들기 | 비슷한 화면을 혼자 만듭니다 |

### 책의 표기

| 이렇게 보이면 | 이런 뜻입니다 |
|---|---|
| 코드 위 이름표 **우리 소스 1–9줄** | 실제 파일을 그대로 옮긴 코드. 이름표 왼쪽이 파일 경로이고 줄 번호도 실제 번호 |
| 코드 위 이름표 **예제 3-1** | 우리 소스에는 없는, 설명하려고 지은 코드 |
| 코드의 형광펜 줄과 ①, `⋮` | 형광펜 줄과 ①은 본문이 짚어 설명하는 곳, `⋮`은 건너뛴 줄 |
| 상자 **팁 · 주의 · 잠깐** | 알아 두면 편한 요령 · 틀리기 쉬운 곳 · 곁가지 설명 |
| 상자 **용어 · 소스 · 해 보기** | 낱말 풀이 · 열어 볼 파일 · 직접 따라 하는 짧은 실습 |
| *형광펜을 칠한 문장* | 그 절에서 가장 중요한 한 문장 |
| [조회], <kbd>F12</kbd> | 화면에 있는 버튼이나 메뉴, 키보드의 키 |

### 읽는 요령

1. **소스를 옆에 열어 두세요.** 장 첫머리 "함께 볼 소스"의 파일을 VS Code로 열어 같은 줄을 찾아봅니다.
2. **"해 보기"는 꼭 손으로 하세요.** 몇 분이면 끝나고, 손으로 해 본 것이 오래 남습니다.
3. **막히면 표시해 두고 넘어가세요.** 14장에서 화면을 만들 때 돌아오면 그때는 잘 읽힙니다.

준비물은 PC에 받아 둔 우리 소스, 개발 도구를 돌려 주는 Node.js, 코드 편집기 VS Code, 크롬이나 엣지 같은 브라우저입니다. PC에 없는 것은 팀에서 받고, 화면을 띄우는 방법은 1장에서 봅니다.
