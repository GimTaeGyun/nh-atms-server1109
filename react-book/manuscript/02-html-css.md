# HTML과 CSS, 화면의 뼈대와 옷

::: lead
화면에 무엇이 놓이는지 적는 HTML과 어떻게 보이는지 적는 CSS를 우리 소스를 읽는 데 필요한 만큼 배웁니다. 이 장을 마치면 개발자 도구에서 요소를 찾아내고, 왜 그런 모양인지 소스에서 짚을 수 있습니다.
:::

::: goals
- 요소·태그·속성이 무엇인지 말하고 `index.html`을 읽을 수 있다
- 우리 화면에 자주 나오는 태그가 무엇을 그리는지 안다
- CSS 규칙의 모양과 박스 모델, flex 배치를 읽을 수 있다
- 개발자 도구로 요소와 그 요소에 입혀진 CSS를 찾을 수 있다
:::

::: files
- `index.html`
- `src/screens/sample/NoticePage.tsx`
- `src/screens/home/home.css`
- `src/theme/global.css`
- `src/components/feedback/LoadingBlock.tsx`
:::

## 태그로 뼈대 세우기 {#ch2-tag}

은행 전표에는 칸마다 이름이 인쇄되어 있습니다. '성명', '금액', '계좌번호'. 같은 숫자라도 어느 칸에 적혔느냐에 따라 금액이 되고 계좌번호가 됩니다. 화면에서도 '공지사항' 네 글자만으로는 그것이 제목인지 버튼에 적힌 글자인지 알 수 없습니다. HTML에서는 @@**태그**|태그@@(tag)가 칸 이름 노릇을 합니다. 태그는 꺾쇠괄호로 둘러싼 표시이고, 글자를 앞뒤에서 감싸 그것이 무엇인지 브라우저에 알려 줍니다.

홈 화면의 [공지사항] 카드 제목은 Elements 탭에서 아래 그림의 한 줄로 보입니다. 여는 태그와 닫는 태그가 내용을 감쌌습니다. 닫는 태그에는 빗금(`/`)이 붙습니다. 여는 태그부터 닫는 태그까지를 통틀어 @@**요소**|요소@@(element)라고 부릅니다. 여는 태그 안에는 @@**속성**|속성(HTML)@@(attribute)을 적습니다. 속성은 요소에 덧붙이는 정보이고 `이름="값"` 모양입니다. *화면은 이런 요소를 쌓아 만듭니다.*

![요소 하나의 생김새. 홈 화면 카드의 제목이다](img/ch02-element.svg){width=90%}

요소 안에는 글자뿐 아니라 다른 요소도 들어갑니다. 감싸는 쪽을 **부모**, 안에 든 쪽을 **자식**이라고 부릅니다. 소스에서는 자식을 안쪽으로 들여 써서 누가 누구 안에 있는지 보이게 합니다. 우리 프로젝트에 HTML 파일은 `index.html` 하나뿐입니다. 14줄 전체를 읽어 봅시다.

```html src="index.html:1-14" hl="11"
<!doctype html>
<html lang="ko">
  <head>
    <meta charset="UTF-8" />
    <link rel="icon" type="image/svg+xml" href="/favicon.svg" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <meta name="color-scheme" content="light" />
    <title>NH농협은행 자동화기기 종합관리시스템</title>
  </head>
  <body>
    <div id="root"></div>
    <script type="module" src="/src/main.tsx"></script>
  </body>
</html>
```

1행은 이 글이 HTML 문서라고 알리는 줄입니다. 2행에서 열린 `html`은 14행에서 닫히고 그 안에 자식이 둘 있습니다. 머리 `head`(3~9행)와 몸 `body`(10~13행)입니다. `head`에는 화면에 그리지 않는 정보를 둡니다. 4행은 한글이 깨지지 않게 글자를 저장한 방식을 알리고, 8행의 `title`은 브라우저 탭에 뜨는 제목입니다. 4~7행의 요소들은 감쌀 내용이 없어서 닫는 태그 없이 혼자 씁니다.

`body`에는 화면에 보이는 것을 둡니다. 그런데 두 줄뿐입니다. 11행의 `div`는 `root`라는 @@`id`|id@@만 있고 내용이 없는 빈 상자입니다. `id`는 문서 안에서 하나뿐인 이름을 붙이는 속성입니다. 12행의 `script`는 `src` 속성에 적힌 자바스크립트 파일을 불러와 실행합니다.

로고도 메뉴도 표도 이 파일에는 없습니다. 그런데 Elements 탭에서 `<div id="root">` 왼쪽의 세모를 눌러 펼치면 그 안에 요소가 겹겹이 들어 있습니다. 12행이 불러온 자바스크립트가 브라우저 안에서 요소를 만들어 채워 넣은 것입니다. Elements 탭은 서버가 준 파일이 아닌 지금 이 순간의 화면을 보여 줍니다. 상자를 채우는 일은 리액트가 맡습니다. [[#ch5]]에서 따라갑니다.

## 자주 만나는 태그 {#ch2-tags}

태그의 종류는 100가지가 넘지만 우리 화면에서 자주 만나는 것은 아래 표의 열 개 남짓입니다. 그 가운데 `div`와 `span`은 뜻이 없는 상자라서, 여럿을 묶어 자리를 잡거나 모양을 입히는 곳마다 나옵니다. `input`과 `img`는 `head`에서 본 `meta`처럼 닫는 태그 없이 혼자 씁니다.

표: 우리 화면에서 자주 만나는 태그

| 태그 | 무엇인가 | 우리 화면의 어디 |
|---|---|---|
| `div` | 구역을 나누는 상자 | 화면 틀, 패널, 카드 등 거의 모든 곳 |
| `span` | 글 한 줄 안의 한 토막 | "(45건)" 같은 건수, 제목 앞의 남색 막대 |
| `h1` | 가장 큰 제목 | 화면 제목 "공지사항" |
| `button` | 누르는 버튼 | [조회], [등록], 헤더의 메뉴 |
| `input` | 글자를 치는 입력 칸 | 조회조건의 검색어 칸 |
| `a` | 누르면 어딘가로 가는 글자(링크) | 목록의 공지 제목 |
| `img` | 그림 | 헤더의 로고 |
| `table` `tr` `th` `td` | 표, 행, 머리 칸, 자료 칸 | 공지 목록, 인쇄용 표 |

표는 요소가 여러 겹으로 들어갑니다. 공지사항 화면의 소스에서 인쇄용 표를 봅니다. 확장자 `.tsx`는 자바스크립트 안에 태그를 적은 파일이라는 뜻이고, 태그를 읽는 법은 `index.html`과 같습니다.

```tsx src="src/screens/sample/NoticePage.tsx:112-123"
        <table>
          <thead>
            <tr><th>순번</th><th>번호</th><th>제목</th><th>사무소</th><th>작성자</th><th>작성일</th><th>조회수</th></tr>
          </thead>
          <tbody>
            // …
          </tbody>
        </table>
```

표 전체가 `table`이고 그 안이 머리 `thead`와 몸 `tbody`로 나뉩니다. 114행의 `tr`이 행 하나이고, 그 안의 머리 칸 `th` 일곱 개가 표의 첫 줄이 됩니다. 건너뛴 117~121행은 공지 한 건마다 `tr` 하나와 자료 칸 `td` 일곱 개를 만드는 코드입니다. 자바스크립트가 섞여 있어 [[#ch5]]에서 읽습니다. 이 표는 [출력]을 눌러 인쇄할 때만 나타납니다.

## CSS로 옷 입히기 {#ch2-css}

HTML만 있으면 화면은 흰 바탕에 검은 글자가 위에서 아래로 늘어설 뿐입니다. 글자를 굵게 하고, 상자에 테두리를 두르고, 버튼을 오른쪽 끝에 놓는 일은 CSS가 합니다. CSS는 **규칙**(rule)을 늘어놓은 글이고, 규칙 하나는 누구에게 무엇을 입힐지 적습니다. 홈 화면 카드의 제목에 옷을 입히는 규칙을 봅니다.

```css src="src/screens/home/home.css:5"
.home-card-title { font-size: 16px; font-weight: 700; margin-bottom: 4px; }
```

중괄호 앞의 `.home-card-title`이 @@**선택자**|선택자@@(selector)입니다. 규칙을 입힐 요소를 고릅니다. 중괄호 안에는 `속성: 값;` 쌍을 늘어놓습니다. 글자 크기는 16px, 글자 굵기는 700(굵게), 아래쪽 바깥 여백은 4px라고 읽습니다. px(픽셀)은 화면의 점을 기준으로 한 길이 단위입니다. 여기의 속성은 태그에 적던 속성과 이름만 같고 다른 것입니다.

선택자 맨 앞의 점(`.`)은 @@**클래스**|클래스(class)@@(class) 이름이라는 표시입니다. 클래스는 요소에 붙이는 별명이고 `class` 속성에 적습니다. [[#ch2-tag]]의 그림에서 본 `class="home-card-title"`이 그것입니다. 브라우저는 이 별명이 붙은 요소를 모두 찾아 규칙을 입힙니다. 그래서 홈 화면의 카드 넉 장 모두 제목이 16px 굵은 글씨입니다. *CSS의 `.이름`과 요소의 `class="이름"`이 짝입니다.* `.tsx` 소스에서는 `class`를 `className`이라고 적으니(까닭은 5장), 짝을 찾을 때는 VS Code 전체 검색에 이름만 넣으세요.

선택자에는 다른 모양도 있습니다. 점 없이 `body`라고 쓰면 그 태그의 요소를, `#root`라고 쓰면 `id`가 `root`인 요소를 고릅니다. `.page-title h1`처럼 띄어 쓰면 `page-title` 안에 든 `h1`을, `.a.b`처럼 붙여 쓰면 두 클래스를 다 가진 요소를 고릅니다.

브라우저는 모든 요소를 네모 상자로 그립니다. 상자는 네 겹입니다. 한가운데에 내용이 있고, 그 둘레를 @@안쪽 여백|안쪽 여백(padding)@@(`padding`), @@테두리|테두리(border)@@(`border`), @@바깥 여백|바깥 여백(margin)@@(`margin`)이 차례로 감쌉니다. 이 네 겹을 @@**박스 모델**|박스 모델@@(box model)이라고 합니다. 요소의 크기와 이웃 요소와의 간격이 이 네 겹의 값으로 정해집니다. 공지사항 화면에서 조회조건을 담은 흰 상자에 입힌 규칙으로 확인해 봅니다.

```css src="src/theme/global.css:88-95"
.search-panel {
  background: var(--bg-panel);
  border: 1px solid var(--border-light);
  border-radius: var(--radius-lg);
  box-shadow: var(--shadow-card);
  padding: 12px 16px;
  margin-bottom: 14px;
}
```

93행의 `padding`은 값을 둘 적으면 앞이 위아래, 뒤가 좌우입니다. 90행의 `border`는 굵기 1px의 실선(`solid`)을 두릅니다. 94행의 `margin-bottom`은 상자 아래를 14px 비워 그 밑의 목록과 떨어뜨립니다. 이 값들을 네 겹에 놓으면 아래 그림이 됩니다. 나머지 89·91·92행은 바탕색, 둥근 모서리, 그림자입니다. 값 자리의 `var(…)`는 [[#ch2-where]]에서 풉니다.

![조회조건 상자의 네 겹. 숫자는 위 규칙의 값이다](img/ch02-box-model.svg){width=92%}

## 줄 세우기, flex {#ch2-flex}

`div`는 가만히 두면 위에서 아래로 한 줄에 하나씩 쌓입니다. 그런데 화면 제목 줄에는 왼쪽에 제목이, 같은 줄 오른쪽 끝에 버튼들이 있습니다. 요소를 가로로 세우고 간격과 정렬을 정할 방법이 필요합니다. 우리 소스에서는 이 일을 거의 다 @@**flex**|flex@@(플렉스)가 맡습니다.

*flex는 부모에 겁니다.* 부모 요소에 `display: flex`를 주면 그 자식들이 가로로 나란히 섭니다. 여기에 속성 셋을 더해 줄을 다듬습니다. `gap`은 자식 사이의 간격입니다. `align-items`는 세로 방향 맞춤이고, `center`면 키가 달라도 가운데를 맞춥니다. `justify-content`는 가로 방향 배치입니다. `center`면 가운데로 모으고 `space-between`이면 양 끝으로 벌립니다.

![flex가 줄을 세우는 모습. 회색 상자가 부모이고 그 안의 상자들이 자식이다](img/ch02-flex.svg){width=100%}

그림에 적힌 `.flex`와 `.flex-between`은 우리 소스에 있는 클래스입니다. 자주 쓰는 묶음에 이름을 붙여 두었습니다.

```css src="src/theme/global.css:68-69"
.flex { display: flex; align-items: center; gap: 8px; }
.flex-between { display: flex; align-items: center; justify-content: space-between; gap: 8px; }
```

요소에 `class="flex-between"`을 붙이면 그 자식들이 양 끝으로 벌어집니다. 모든 화면의 제목 줄이 이 배치입니다. 그 규칙인 `src/components/page/page.css` 5행도 69행과 같은 세 속성을 씁니다.

![공지사항 화면의 제목 줄. 제목 묶음과 버튼 묶음이 양 끝에 놓였다](img/shots/part-pageframe-title.png){width=100%}

CSS 파일에 규칙을 만들지 않고 요소에 직접 적기도 합니다. @@`style` 속성|style 속성@@을 씁니다. "불러오는 중…" 표시를 그리는 부품의 한 줄입니다.

```tsx src="src/components/feedback/LoadingBlock.tsx:4"
  <div style={{ display: 'flex', alignItems: 'center', justifyContent: 'center', height, color: 'var(--text-muted)', gap: 10 }}>
```

익숙한 이름 셋이 보입니다. `.tsx` 파일 안이라 `style={{ … }}`로 감싸고 `align-items`를 `alignItems`처럼 붙여 적지만 뜻은 같습니다([[#ch5]]). 가로도 세로도 `center`이니 내용이 상자 한가운데에 놓입니다. 배치 방법에는 행과 열을 바둑판처럼 나누는 `grid`도 있습니다. 우리 소스에서는 화면 전체의 틀을 나눌 때 씁니다.

## 우리 소스의 CSS가 사는 곳 {#ch2-where}

우리 소스의 CSS 파일은 여섯 개, 모두 합쳐 554줄입니다. 앱 전체가 함께 쓰는 규칙은 `src/theme/global.css`에 있고, 나머지 다섯은 `home.css`처럼 자기가 꾸미는 부품 파일 옆에 있습니다. 어느 파일에 적든 규칙은 앱 전체에 걸립니다. 그래서 클래스 이름 앞에 `home-`, `page-` 같은 말을 붙여 서로 겹치지 않게 합니다.

`global.css`의 맨 앞에는 색과 크기에 이름을 붙여 둔 목록이 있습니다. 같은 남색을 여기저기에 직접 적어 두면 색을 바꾸는 날 그 자리를 모두 찾아 고쳐야 하기 때문입니다. 이렇게 이름 붙인 값이 @@**CSS 변수**|CSS 변수@@입니다. 16행의 `--primary: #054681;`은 남색 `#054681`에 `--primary`라는 이름을 붙입니다. `#`과 여섯 글자는 색을 숫자로 적는 표기입니다. 꺼내 쓸 때는 `var(--primary)`라고 적습니다. `home.css` 4행의 `color: var(--primary);`가 홈 화면 카드의 아이콘을 남색으로 칠합니다. `color`는 글자색입니다. 우리 CSS에는 `var(--primary)`가 스무 군데 넘게 나오고, 16행의 값 하나를 바꾸면 모두 함께 바뀝니다.

버튼, 입력 칸, 표, 달력의 모양은 여섯 CSS 파일 어디에도 없습니다. 이 부품들은 antd가 만든 것이고 옷도 antd가 입혀서 옵니다. 우리 CSS는 그 위에 조금 덧입힐 뿐입니다. 직접 확인해 봅시다.

2. `<button type="submit" class="ant-btn … search-btn">`으로 시작하는 줄이 칠해집니다. `class`에 이름이 여럿 띄어 적혀 있습니다. `ant-`로 시작하는 이름은 antd가, 맨 끝의 `search-btn`은 우리 소스가 붙인 클래스입니다.
3. 옆의 Styles 칸에는 이 버튼에 입혀진 규칙이 쌓여 있고, 거의 다 `.ant-btn`으로 시작합니다. 그 사이에서 `.search-btn.ant-btn` 규칙을 찾아 `min-width`의 `130px`을 `300px`로 고치고 <kbd>Enter</kbd>를 누릅니다. 버튼이 길어집니다.
4. <kbd>F5</kbd>로 새로 고치면 원래대로 돌아옵니다. 개발자 도구에서 고친 것은 지금 내 브라우저의 화면뿐이고 소스 파일은 그대로입니다.
:::

화면을 만들 때 CSS를 새로 쓸 일은 드뭅니다. 14장에서 만드는 공지사항 화면의 파일 여섯 개에 CSS 파일은 없습니다. 모양을 직접 적은 곳은 팝업 아래쪽 버튼을 오른쪽으로 모으는 `style` 한 줄뿐이고, 그것도 이 장에서 본 flex입니다. 지금은 `className`과 `style`을 만났을 때 무엇을 하는 글인지 알아보면 충분합니다. 뼈대와 옷을 보았으니 [[#ch3]]에서는 움직임, 자바스크립트를 배웁니다.

::: summary
- 요소는 여는 태그, 내용, 닫는 태그로 이루어진다. 여는 태그에는 속성을 적는다.
- `index.html`의 `body`에는 빈 상자 `<div id="root">`와 `script`뿐이다. 화면은 자바스크립트가 채운다.
- CSS 규칙은 `선택자 { 속성: 값; }` 모양이다. `.이름`은 `class="이름"`이 붙은 요소를 고른다.
- 모든 요소는 내용, `padding`, `border`, `margin` 네 겹의 상자다. 부모에 `display: flex`를 주면 자식이 가로로 선다.
- CSS 파일은 여섯 개뿐이다. 버튼과 표의 모양은 antd가 주고, 색은 `var(--이름)`으로 꺼내 쓴다.
:::

::: quiz
1. `index.html`의 `body`에는 요소가 둘뿐인데, Elements 탭에서 `body`를 펼치면 요소가 수백 개 나옵니다. 어떻게 된 일입니까?
2. `global.css` 65행에 `.muted { color: var(--text-muted); }`라는 규칙이 있습니다. 이 규칙은 어떤 요소에 무엇을 입힙니까? 실제 색 값은 어디에 적혀 있습니까?
3. 한 줄의 왼쪽 끝에 제목을, 오른쪽 끝에 버튼을 놓으려고 합니다. 제목, 버튼, 둘을 감싼 부모 가운데 어느 요소에 어떤 CSS를 줍니까?
:::
::: answer
1. 12행의 `script`가 불러온 자바스크립트가 `<div id="root">` 안에 요소를 만들어 넣었다. Elements 탭은 지금의 화면을 보여 준다.
2. `class`에 `muted`가 있는 요소의 글자색. 색 값은 `global.css` 맨 앞의 `--text-muted` 줄에 있다.
3. 부모에 `display: flex`와 `justify-content: space-between`. 우리 소스에서는 부모에 `class="flex-between"`을 붙이면 된다.
:::
