# 자바스크립트, 꼭 필요한 문법만

::: lead
우리 소스에 가장 자주 나오는 자바스크립트 문법만 골라 배웁니다. 변수와 함수에서 시작해 객체와 배열, 조건을 짧게 쓰는 기호, 파일을 잇는 `import`, 기다리는 코드 `await`까지 갑니다. 이 장을 마치면 소스 파일의 낯선 기호들이 뜻으로 읽힙니다.

## 값과 변수 {#ch3-value}

공지사항 화면에 보이는 것을 하나씩 짚어 보면 모두 **값**(value)입니다. 번호 264, 제목 '기기 장애 통계 주간 보고', 체크 상자가 켜졌는지 꺼졌는지. 프로그램은 값을 받아 계산하고, 값을 화면에 그립니다.

우리 소스에서 날마다 만나는 값은 네 가지입니다. 숫자는 `264`처럼 그대로 적습니다. 글자는 `'공지사항'`처럼 따옴표로 감싸 적고 **문자열**(string)이라고 부릅니다. 켜짐과 꺼짐처럼 둘 중 하나인 것은 `true`와 `false`로 적고 **참거짓**(boolean) 값이라고 합니다. 마지막은 값이 없다는 표시인 `null`과 `undefined`입니다. `undefined`는 아직 아무것도 담지 않았을 때 자바스크립트가 스스로 붙이고, `null`은 비어 있다는 것을 사람이 일부러 적을 때 씁니다.

값은 이름을 붙여 두고 씁니다. 창구 서랍마다 '입금 전표', '출금 전표'라고 이름표를 붙여 두면 다음부터는 이름만 보고 꺼냅니다. 이름이 붙은 값을 @@**변수**|변수@@(variable)라고 합니다.

```js title="예제 3-1 값에 이름 붙이기"
const waiting = 27;               // 숫자
const title = '시스템 점검 안내';  // 문자열
const isOpen = true;              // 참거짓
let count = 0;
count = count + 1;                // count는 이제 1
```

`const 이름 = 값;`이 한 문장입니다. 여기서 `=`는 오른쪽 값을 왼쪽 이름에 담으라는 기호이고, 수학의 '같다'와 다릅니다. 문장 끝에는 세미콜론(`;`)을 찍습니다. `//` 뒤는 **주석**(comment)입니다. 사람이 읽으라고 적어 둔 메모이고 실행되지 않습니다. 우리 소스에는 `/** … */`로 감싼 주석도 많습니다.

이름을 붙이는 낱말은 둘입니다. @@`const`|const@@로 붙인 이름에는 다른 값을 다시 담지 못합니다. `let`으로 붙인 이름에는 예제의 마지막 줄처럼 다시 담을 수 있습니다. 우리 소스는 거의 다 `const`를 쓰고 `let`은 20번 남짓 나옵니다. 이름이 끝까지 같은 값을 가리키면, 읽는 사람이 중간에 값이 바뀌었는지 살피지 않아도 됩니다.

```ts src="src/config/constants.ts:8-9"
/** 열린 화면 탭 최대 개수 */
export const MAX_OPEN_TABS = 12;
```

8행은 주석이고, 9행이 12라는 숫자에 `MAX_OPEN_TABS`라는 이름을 붙입니다. 코드 여기저기에 12를 직접 적는 대신 이 이름을 씁니다. 그러면 12가 무슨 숫자인지 이름이 말해 주고, 13으로 바꾸는 날에는 이 한 줄만 고칩니다. 맨 앞의 `export`는 [[#ch3-module]]에서 배웁니다.

문자열 사이에 변수의 값을 끼워 넣을 일이 많습니다. 그럴 때는 따옴표 대신 백틱(`` ` ``)으로 감싸고, 값을 넣을 자리에 `${ }`를 씁니다. 이것이 @@**템플릿 문자열**|템플릿 문자열@@(template literal)입니다. 백틱은 키보드에서 숫자 1의 왼쪽에 있습니다. 방금 본 `MAX_OPEN_TABS`를 쓰는 줄이 좋은 예입니다.

```ts src="src/screens/navigation.ts:31"
        notifyError(`열 수 있는 화면 탭은 최대 ${MAX_OPEN_TABS}개입니다. 사용하지 않는 탭을 닫고 다시 시도하세요.`);
```

탭이 꽉 찼을 때 알림을 띄우는 줄입니다. 괄호 안의 백틱 문자열만 보세요. 자바스크립트가 `${ }` 안의 값을 글자 사이에 끼워서 "…최대 12개입니다. …"라는 문자열이 됩니다. 중괄호 안에는 `MAX_OPEN_TABS - 1` 같은 계산을 적어도 됩니다.

::: try 콘솔에 직접 쳐 보기
1. 우리 화면을 띄운 브라우저에서 <kbd>F12</kbd>를 누르고 Console 탭을 고릅니다. `>` 옆에서 커서가 깜박입니다.
2. `const waiting = 27`을 치고 <kbd>Enter</kbd>를 누릅니다. `undefined`가 찍히면 잘된 것입니다. 이름을 붙이는 문장에는 돌려줄 값이 없어서 그렇습니다.
3. `waiting - 1`을 치면 26이, `` `대기 번호 ${waiting}번` ``을 치면 '대기 번호 27번'이 찍힙니다.
4. `waiting = 30`을 쳐 보세요. `Assignment to constant variable`이라는 빨간 글이 뜹니다. `const`로 붙인 이름에 다시 담으려 했다는 오류입니다.
:::

## 함수 {#ch3-function}

공지사항 표 아래에는 "총 45건"이라는 글자가 찍힙니다. 기기정보 표 아래에도 같은 모양의 글자가 있고 숫자만 다릅니다. 숫자를 받아 "총 ○건"이라는 문자열을 만드는 일이 화면마다 되풀이됩니다. 되풀이되는 일에 이름을 붙여 둔 것이 @@**함수**|함수@@(function)입니다.

함수는 창구 업무 하나와 닮았습니다. 손님이 전표에 금액을 적어 내면 직원은 정해진 순서대로 처리하고 결과를 내줍니다. 함수도 값을 받아 정해진 일을 하고 결과를 돌려줍니다. 받는 값의 자리를 @@**매개변수**|매개변수@@(parameter), 실제로 넘기는 값을 **인자**(argument), 돌려주는 값을 **반환값**(return value)이라고 합니다. 전표의 빈칸이 매개변수이고 거기 적어 낸 금액이 인자입니다.

```js title="예제 3-2 같은 함수, 세 가지 모양" marks="1=①;5=②;9=③"
function callA(no) {
  return `${no}번 손님, 창구로 오세요.`;
}

const callB = (no) => {
  return `${no}번 손님, 창구로 오세요.`;
};

const callC = (no) => `${no}번 손님, 창구로 오세요.`;

callC(27);  // '27번 손님, 창구로 오세요.'
```

세 함수는 하는 일이 같습니다. ① 은 `function`으로 시작하는 함수 선언입니다. 이름 `callA`, 괄호 안의 매개변수 `no`, 중괄호 안의 할 일이 차례로 옵니다. `return` 뒤의 값이 반환값이고, `return`을 만나면 함수는 거기서 끝납니다.

② 는 @@**화살표 함수**|화살표 함수@@(arrow function)입니다. `(매개변수) => { 할 일 }`이 함수이고, 거기에 `const`로 이름을 붙였습니다. 함수도 값이라서 숫자나 문자열처럼 이름을 붙여 둡니다. ③ 은 ② 를 줄인 것입니다. 할 일이 `return` 한 줄뿐이면 중괄호와 `return`을 함께 지우고, 화살표 뒤에 반환값만 적습니다.

함수는 이름 뒤에 괄호를 붙여 부릅니다. 마지막 줄의 `callC(27)`은 인자 27을 넘겨 부른 것입니다. 27이 매개변수 `no`에 담기고, 완성된 문자열이 돌아옵니다. 우리 소스에서 ① 모양은 13개뿐이고 나머지 함수는 모두 화살표 함수입니다. "총 45건"을 만드는 함수도 그렇습니다.

```tsx src="src/components/grid/DataGrid.tsx:11"
const showTotal = (t: number) => `총 ${fmtCount(t)}건`;
```

③ 모양입니다. 매개변수는 `t` 하나이고, 화살표 뒤의 템플릿 문자열이 반환값입니다. `${ }` 안에서는 `fmtCount`라는 다른 함수를 불렀습니다. 숫자에 천 단위 쉼표를 넣어 주는 함수입니다. 그래서 `showTotal(45)`는 '총 45건'을, `showTotal(12345)`는 '총 12,345건'을 돌려줍니다. 아래 그림의 왼쪽 끝이 이 함수가 만든 글자입니다.

![공지사항 표 아래의 쪽 번호 줄. 왼쪽 끝의 글자를 `showTotal`이 만든다](img/shots/ch03-total.png){width=80%}

할 일이 여러 줄인 함수도 읽어 봅시다. 이름의 가운데 글자를 별표로 가리는 함수입니다.

```ts src="src/utils/mask.ts:19-24"
export const maskName = (v?: string | null): string => {
  if (!v) return '-';
  if (v.length <= 1) return v;
  if (v.length === 2) return `${v[0]}*`;
  return `${v[0]}${'*'.repeat(v.length - 2)}${v[v.length - 1]}`;
};
```

② 모양입니다. 19행에서 매개변수 `v`로 이름을 받습니다. `v` 뒤의 물음표도 타입 표기입니다. 20~22행은 모두 `if (조건) return 값;` 꼴입니다. 조건이 맞으면 그 자리에서 값을 돌려주고 함수를 끝냅니다. 조건을 읽는 법은 [[#ch3-cond]]에서 배웁니다. 지금은 20행을 "이름이 없으면", 21행을 "한 글자 이하이면", 22행을 "두 글자이면"으로 읽으세요.

23행까지 내려왔다면 이름은 세 글자 이상입니다. `v.length`는 글자 수이고 `v[0]`은 첫 글자입니다. 자바스크립트는 순서를 0부터 셉니다. 그래서 마지막 글자는 `v[v.length - 1]`입니다. `'*'.repeat(n)`은 별표를 n번 되풀이한 문자열을 만듭니다. `repeat`처럼 값 뒤에 점을 찍고 부르는 함수를 **메서드**(method)라고 합니다. 그래서 `maskName('김하늘')`은 23행까지 가서 '김\*늘'을 돌려줍니다.

매개변수에는 기본값을 정해 둘 수 있습니다. `(no, desk = 3) => …`이라고 적으면, 둘째 인자를 넘기지 않았을 때 `desk`에 3이 담깁니다. `src/utils/format.ts` 10행의 `sep = '-'`가 이 모양입니다. 날짜 사이에 넣을 글자를 따로 넘기지 않으면 줄표를 씁니다. *함수는 값을 받아 값을 돌려줍니다.* 받는 자리가 매개변수이고, 돌려주는 자리가 `return`이나 화살표의 뒤쪽입니다.

## 객체와 배열 {#ch3-object}

공지 한 건에는 번호와 제목과 조회수가 함께 다닙니다. 변수 셋에 따로 담으면 공지가 20건일 때 변수는 60개가 됩니다. 한 건에 딸린 값을 한데 묶은 것이 @@**객체**|객체@@(object)입니다. 전표 한 장을 떠올리면 됩니다. 전표에는 '계좌번호', '금액', '예금주' 칸이 있고 칸마다 값이 적혀 있습니다. 객체도 이름 붙은 칸에 값을 하나씩 담습니다.

```js title="예제 3-3 객체 만들고 꺼내기" nums
const notice = { no: 264, subject: '기기 장애 통계 주간 보고', visit: 14 };
notice.subject;    // '기기 장애 통계 주간 보고'
notice.writer;     // undefined

const page = 1;
const size = 20;
const params = { page, size };  // { page: page, size: size }와 같다
```

중괄호 안에 `이름: 값`을 쉼표로 이어 적습니다. 칸 하나하나를 **속성**(property)이라고 합니다. 꺼낼 때는 객체 이름 뒤에 점을 찍고 속성 이름을 씁니다. 없는 속성을 꺼내면 오류가 나지 않고 `undefined`가 나옵니다. 1장의 예제 1-1에서 본 JSON이 이 객체를 글자로 옮겨 적은 것입니다. 서버가 보낸 JSON은 브라우저 안에서 객체가 됩니다.

7행은 @@**줄임 속성**|줄임 속성@@입니다. 속성 이름과 거기 담을 변수의 이름이 같으면 한 번만 적습니다. 우리 소스는 줄일 수 있으면 늘 줄입니다. 콜론 없는 속성을 만나면 같은 이름의 변수를 찾으세요.

공지가 여러 건이면 순서대로 줄 세워 담을 그릇이 필요합니다. 전표를 차례로 철해 둔 묶음에 해당하는 것이 @@**배열**|배열@@(array)입니다. 대괄호 안에 값을 쉼표로 이어 적습니다. `const waiting = [25, 26, 27];`이라고 만들었다면 `waiting[0]`은 25이고 `waiting.length`는 3입니다. 꺼낼 때는 대괄호 안에 순서를 적는데, 문자열의 글자를 셀 때처럼 0부터 셉니다. `length`는 들어 있는 개수입니다. 칸이 셋이니 마지막 칸은 `waiting[2]`이고, 없는 칸인 `waiting[3]`은 `undefined`입니다.

배열의 칸마다 객체를 담으면 표가 됩니다. 아래 그림을 보세요. 객체 하나가 표의 행 하나가 되고, 속성 하나가 세로 칸인 컬럼 하나가 됩니다. 서버가 보내는 공지 목록이 이 모양이고, 공지사항 화면의 표는 이 배열을 그린 것입니다.


12행에서 `CARDS` 뒤의 콜론부터 `=` 앞까지는 타입 표기입니다. 걷어 내면 `const CARDS = [`가 남습니다. 대괄호 안에 객체가 넷 있고(13~16행), 객체마다 속성이 `key`, `title`, `desc`, `icon` 넷입니다. `CARDS[1].title`은 둘째 객체의 제목인 '공지사항'입니다. `icon`의 값은 태그처럼 생겼는데 [[#ch5]]에서 배웁니다. 1장에서 본 홈 화면의 카드 넉 장이 이 네 줄에서 나옵니다.

## 구조 분해와 전개 연산자 {#ch3-destructure}

객체에서 값을 꺼낼 때마다 `notice.subject`, `notice.visit`처럼 점을 찍으면 코드가 길어집니다. 여러 값을 한 번에 꺼내 이름을 붙이는 문법이 @@**구조 분해**|구조 분해@@(destructuring)입니다.

```js title="예제 3-4 구조 분해" nums
const notice = { no: 264, subject: '기기 장애 통계 주간 보고', visit: 14 };
const { subject, visit } = notice;

const waiting = [25, 26, 27];
const [first, second] = waiting;

const label = ({ no, subject }) => `${no}번 ${subject}`;
label(notice);  // '264번 기기 장애 통계 주간 보고'
```

2행 왼쪽의 중괄호는 객체를 만들지 않습니다. `notice`에서 `subject`와 `visit` 속성을 꺼내 같은 이름의 변수 둘을 만듭니다. 객체는 이름으로 찾아 꺼냅니다. 5행은 배열입니다. 배열은 자리로 꺼내므로 `first`에 첫 칸의 25가, `second`에 둘째 칸의 26이 담깁니다. 이름은 마음대로 짓습니다.

7행은 매개변수 자리에서 꺼냅니다. 객체를 받자마자 `no`와 `subject`만 꺼내 씁니다. 리액트에서는 부품마다 첫 줄에 이 모양이 나옵니다([[#ch6]]). 우리 소스의 두 줄을 읽어 봅시다.

```ts src="src/hooks/usePagedSearch.ts:46"
  const { params, setParams, query, refetch, reset } = core;
```

```tsx src="src/screens/sample/NoticePage.tsx:34"
  const [form] = Form.useForm();
```

첫 줄은 `core`라는 객체에서 속성 다섯을 한꺼번에 꺼냅니다. 둘째 줄은 `Form.useForm()`이라는 함수가 돌려준 배열에서 첫 칸을 꺼내 `form`이라고 부릅니다. 함수가 값을 배열에 담아 돌려주고, 받는 쪽이 구조 분해로 꺼내는 모양입니다. [[#ch7]]부터는 이 모양을 날마다 만납니다.

이번에는 공지 목록에서 2쪽으로 넘어간다고 해 봅시다. 조회조건은 그대로이고 쪽 번호만 다른 객체가 필요합니다. `const`로 만든 객체도 `prev.page = 2`처럼 속성은 고칠 수 있습니다. 하지만 우리 소스는 속을 고치는 대신 새 객체를 만듭니다. 이때 점 세 개 `...`으로 쓰는 @@**전개 연산자**|전개 연산자@@(spread)를 씁니다. 객체나 배열 앞에 붙이면 안에 든 것을 그 자리에 펼쳐 놓습니다.

```js title="예제 3-5 전개 연산자" nums
const prev = { keyword: '점검', page: 1, size: 20 };
const next = { ...prev, page: 2 };
// next는 { keyword: '점검', page: 2, size: 20 }

const waiting = [25, 26, 27];
const more = [...waiting, 28];
// more는 [25, 26, 27, 28]
```

아래 그림은 2행에서 일어나는 일입니다. `...prev`가 `prev`의 속성 셋을 새 객체에 베껴 놓습니다. 이어서 적은 `page: 2`가 같은 이름의 칸을 덮어씁니다. 같은 이름이 두 번 나오면 뒤에 적은 쪽이 남습니다. `prev`는 손대지 않았으니 그대로입니다. 배열도 같습니다. 6행은 `waiting`의 값 셋을 펼치고 28을 덧붙여 새 배열을 만듭니다.

![`{ ...prev, page: 2 }`가 하는 일. 베껴 놓은 뒤에 덮어쓴다](img/ch03-spread.svg){width=100%}

공지사항 표 아래의 쪽 번호를 누르면 불리는 함수가 이 문법을 씁니다.

```ts src="src/hooks/usePagedSearch.ts:52"
  const setPage = useCallback((page: number, size: number) => setParams((prev) => (prev ? { ...prev, page, size } : prev)), [setParams]);
```

긴 줄이지만 지금 읽을 곳은 가운데의 `{ ...prev, page, size }`뿐입니다. 이전 조회조건 `prev`를 펼쳐 놓고 `page`와 `size`를 덮어씁니다. 줄임 속성이니 `page: page, size: size`입니다. 조건은 그대로이고 쪽만 바뀐 새 객체가 만들어집니다. *원본은 그대로 두고, 바뀐 새것을 만듭니다.* 리액트에서 이 습관이 왜 중요한지는 [[#ch7]]에서 배웁니다.

## 조건을 짧게 쓰는 법 {#ch3-cond}

프로그램은 경우에 따라 다른 일을 합니다. 기다리는 손님이 없으면 "바로 오세요", 있으면 "3명 대기"라고 알려 주는 함수를 두 가지로 적어 봅니다.

```js title="예제 3-6 if와 삼항 연산자" nums
const guideA = (waiting) => {
  if (waiting === 0) return '바로 오세요';
  return `${waiting}명 대기`;
};

const guideB = (waiting) => (waiting === 0 ? '바로 오세요' : `${waiting}명 대기`);

guideB(3);  // '3명 대기'
```

2행의 `===`는 양쪽이 같은지 묻는 기호이고 답은 `true`나 `false`입니다. 다른지 물을 때는 `!==`, 크기를 견줄 때는 `<`, `>`, `<=`, `>=`를 씁니다. `if (조건)`은 조건이 참일 때만 바로 뒤의 일을 합니다. `guideA`는 `maskName`과 같은 글버릇으로 썼습니다. 조건에 맞는 경우를 먼저 돌려보내고, 남은 경우만 아래로 내려갑니다. "아니면"을 뜻하는 `else`라는 낱말도 있지만 우리 소스에는 8번밖에 나오지 않습니다.

6행의 `조건 ? A : B`는 @@**삼항 연산자**|삼항 연산자@@(ternary operator)입니다. 조건이 참이면 A가, 거짓이면 B가 그 자리의 값이 됩니다. `if`는 할 일을 가르고, 삼항 연산자는 값을 고릅니다. 값이 들어갈 자리라면 어디에나 쓸 수 있어서 우리 소스에 수백 번 나옵니다.

조건 자리에 `true`와 `false`만 오는 것은 아닙니다. 자바스크립트는 `false`, `0`, 빈 문자열 `''`, `null`, `undefined`를 거짓으로 치고, 그 밖의 값은 거의 다 참으로 칩니다. 앞에 `!`를 붙이면 참과 거짓이 뒤집힙니다. 이제 `maskName` 20행의 `if (!v)`가 읽힙니다. `v`가 `null`이거나 `undefined`이거나 빈 문자열이면 `!v`가 참이 됩니다. 우리 소스는 이 성질을 이용한 기호 넷을 더 씁니다.

표: 조건을 짧게 쓰는 기호

| 기호 | 읽는 법 | 주로 쓰는 곳 |
|---|---|---|
| `조건 ? A : B` | 조건이 참이면 A, 아니면 B | 둘 중 하나 고르기 |
| `A && B` | A가 참으로 통하면 B, 아니면 A | A가 있을 때만 B |
| `A \|\| B` | A가 참으로 통하면 A, 아니면 B | A가 비었으면 대신 B |
| `A ?? B` | A가 `null`·`undefined`면 B, 아니면 A | A가 없으면 대신 B |
| `A?.b` | A가 `null`·`undefined`면 `undefined`, 아니면 `A.b` | 없을지 모르는 객체에서 꺼내기 |

`||`와 `??`는 닮았지만 0과 빈 문자열을 다르게 다룹니다. 조회수 `visit`이 0인 공지를 생각해 보세요. `visit || '-'`는 0을 거짓으로 쳐서 '-'를 내놓습니다. `visit ?? '-'`는 0을 그대로 내놓습니다. 0도 엄연한 값이니, 값이 정말 없을 때만 바꾸려면 @@**널 병합 연산자**|널 병합 연산자@@(nullish coalescing) `??`를 씁니다. 빈 문자열까지 바꾸고 싶을 때는 `||`를 씁니다. `src/screens/sample/NoticeParts.tsx` 96행의 `v || '(제목 없음)'`이 그렇습니다.

`?.`은 @@**옵셔널 체이닝**|옵셔널 체이닝@@(optional chaining)입니다. 로그인한 사람의 정보를 담은 객체 `me`가 아직 `null`일 때 `me.name`이라고 쓰면 오류가 납니다. `null`에는 꺼낼 속성이 없기 때문입니다. `me?.name`은 `me`가 없으면 거기서 멈추고 `undefined`를 내놓습니다. 홈 화면의 인사말이 이 기호들을 한 줄에 씁니다.

```tsx src="src/screens/home/HomePage.tsx:26"
        <b>{me?.name ?? '-'}</b>님{me?.kanm ? ` (${me.kanm})` : ''}, NH-ATMS 공통 뼈대 + 견본입니다. 아래 견본 화면을 열어 보세요.
```

태그 사이의 중괄호 두 개만 봅니다. 중괄호 안은 자바스크립트이고 그 값이 화면에 찍힙니다. 첫째 `me?.name ?? '-'`에서 `me`가 아직 없으면 `?.`이 `undefined`를 내놓고, `??`가 그것을 '-'로 바꿉니다. `me`가 있으면 이름이 나옵니다. *`?.`과 `??`는 이렇게 짝으로 다닙니다.* 둘째는 삼항 연산자입니다. 사무소 이름 `me.kanm`이 있으면 괄호로 감싼 문자열을, 없으면 빈 문자열을 고릅니다. 그래서 화면에는 "김하늘님 (가람지점), …"이라고 찍힙니다.

## 배열을 다루는 함수 {#ch3-array}

공지 목록에서 제목만 뽑거나 조회수가 많은 것만 고르려면 배열의 항목을 하나씩 살펴야 합니다. 배열에는 이런 일을 맡는 메서드가 딸려 있습니다. 쓰는 법이 조금 낯섭니다. 항목마다 무엇을 할지를 함수로 적어 건넵니다.

창구에 서류 묶음을 내밀며 "장마다 도장을 찍어 주세요" 하고 방법을 일러 주는 것과 같습니다. 묶음을 한 장씩 넘기는 일은 직원이 하고, 손님은 한 장에 할 일만 말합니다. 이렇게 다른 함수에 건네 두면 그쪽이 필요할 때 불러 주는 함수를 @@**콜백**|콜백@@(callback)이라고 합니다. 함수도 값이라서 인자로 건넬 수 있습니다.

```js title="예제 3-7 map과 filter" nums
const notices = [
  { no: 264, subject: '기기 장애 통계 주간 보고', visit: 14 },
  { no: 261, subject: '현금 준비 안내', visit: 29 },
  { no: 260, subject: '청소 일정 변경 안내', visit: 10 },
];

const subjects = notices.map((n) => n.subject);
const popular = notices.filter((n) => n.visit >= 14);
```

7행의 @@`map`|map@@은 항목마다 콜백을 부르고, 콜백이 돌려준 값을 모아 새 배열을 만듭니다. 콜백 `(n) => n.subject`는 공지 하나를 `n`으로 받아 제목을 돌려줍니다. 그래서 `subjects`는 제목 셋이 든 배열입니다. 8행의 `filter`는 콜백이 참을 돌려준 항목만 남깁니다. `popular`에는 264번과 261번 공지 둘이 남습니다. 두 메서드 모두 새 배열을 돌려주고 원래 배열 `notices`는 건드리지 않습니다.

아래 그림은 같은 일을 숫자 셋으로 그린 것입니다. `map`은 들어간 개수만큼 나오고, `filter`는 걸러진 만큼 줄어듭니다. 콘솔에 `[25, 26, 27].map((n) => n + 1)`을 쳐서 확인해 보세요.

![`map`과 `filter`. 건넨 콜백이 항목마다 한 번씩 불린다](img/ch03-map-filter.svg){width=100%}

콜백을 받는 메서드는 더 있습니다. `find`는 조건에 맞는 첫 항목 하나를 돌려주고, 없으면 `undefined`를 돌려줍니다. `some`은 맞는 항목이 하나라도 있으면 `true`입니다. `includes`는 콜백 대신 값을 받아 그 값이 들어 있는지 알려 줍니다. `[264, 261].includes(260)`은 `false`입니다. 실제 코드를 읽어 봅니다. 서버에서 받은 코드 목록 `items`를 고르는 칸에 넣을 모양으로 바꾸는 두 줄입니다.

```ts src="src/hooks/useCodes.ts:13-14"
  const live = items.filter((c) => c.useYn !== 'N');
  const options: Option[] = live.map((c) => ({ value: c.code, label: c.codeNm ?? c.code }));
```

13행은 사용 여부 `useYn`이 'N'이 아닌 코드만 남깁니다. 14행은 남은 코드를 하나씩 `{ value, label }` 객체로 바꿉니다. `label`에는 코드 이름 `codeNm`을 넣고, 이름이 없으면 `??` 뒤의 코드를 넣습니다. 화살표 뒤의 객체를 소괄호로 감싼 것도 보세요. 소괄호가 없으면 자바스크립트는 이 중괄호를 할 일을 감싸는 중괄호로 읽습니다.

화면 제목 옆의 별을 누르면 그 화면이 즐겨찾기에 들어가고, 한 번 더 누르면 빠집니다. 그 일을 하는 한 줄에 앞의 세 절에서 배운 문법이 모여 있습니다.

```ts src="src/stores/useFavoriteStore.ts:24"
      toggle: (id) => set((s) => ({ favorites: s.favorites.includes(id) ? s.favorites.filter((x) => x !== id) : [...s.favorites, id] })),
```

가운데의 삼항 연산자만 읽습니다. 조건은 `s.favorites.includes(id)`, 곧 "즐겨찾기 배열에 이 화면이 들어 있는가"입니다. 들어 있으면 `filter`로 그 화면만 뺀 새 배열을 고릅니다. 없으면 전개 연산자로 끝에 덧붙인 새 배열을 고릅니다. 어느 쪽이든 원래 배열은 고치지 않습니다. 바깥의 `set`은 [[#ch11]]에서 배웁니다.

## 파일을 나누고 잇기, import와 export {#ch3-module}

우리 소스는 파일 180개에 12,000줄 가까이 됩니다. 한 파일에 다 적으면 찾을 수도 고칠 수도 없습니다. 그래서 일거리별로 파일을 나누는데, 이 파일 하나하나를 **모듈**(module)이라고 합니다. 파일 안에서 붙인 이름은 그 파일 안에서만 통합니다. 다른 파일에서 쓰게 하려면 @@`export`|export@@로 내보내고, 쓰는 쪽에서 @@`import`|import@@로 가져옵니다.

[[#ch3-value]]에서 읽은 `constants.ts` 9행이 `export const MAX_OPEN_TABS = 12;`였습니다. `const` 앞의 `export`가 이 이름을 내보냅니다. 그 이름을 템플릿 문자열에 끼워 쓰던 `navigation.ts`의 맨 위를 봅니다.

```ts src="src/screens/navigation.ts:1-8" hl="4"
import { useCallback } from 'react';
import { useNavigate } from 'react-router-dom';
// …
import { MAX_OPEN_TABS } from '@/config/constants';
import { notifyError } from '@/hooks/useAppMessage';
import { getScreen, screenPath } from './registry';
```

6행이 `MAX_OPEN_TABS`를 가져옵니다. `import { 이름 } from '파일';` 꼴입니다. 중괄호 안의 이름은 내보낸 이름과 글자 하나까지 같아야 합니다. 8행처럼 쉼표로 여러 이름을 한꺼번에 가져오기도 합니다. `from` 뒤의 글자는 어디서 가져오는지를 말하고, 세 가지로 읽습니다.

- `'./registry'`: 점으로 시작하면 지금 파일에서 따라가는 길입니다. `./`는 같은 폴더, `../`는 한 칸 위 폴더입니다.
- `'@/config/constants'`: `@/`는 `src/` 폴더를 가리키는 우리 프로젝트의 약속입니다.
- `'react'`, `'react-router-dom'`: 점도 `@/`도 없으면 1장에서 `npm ci`로 설치한 라이브러리의 이름입니다.

파일 이름 끝의 `.ts`와 `.tsx`는 적지 않습니다. 이제 앱의 맨 위에 있는 파일을 통째로 읽어 봅니다. 9줄입니다.

```tsx src="src/app/App.tsx:1-9"
import { AppProviders } from './providers';
import { AppRouter } from './router';

const App = () => (
  <AppProviders>
    <AppRouter />
  </AppProviders>
);
export default App;
```

1~2행은 같은 폴더의 `providers.tsx`와 `router.tsx`에서 이름 하나씩을 가져옵니다. 4~8행은 `App`이라는 화살표 함수입니다. 돌려주는 것이 태그 모양인데 5장에서 읽습니다. 9행의 `export default`는 이 파일의 대표 하나를 내보낸다는 뜻입니다. 대표를 가져올 때는 중괄호를 쓰지 않습니다. `src/main.tsx` 3행의 `import App from './app/App';`이 그 모양입니다. 우리 소스에서 `export default`를 쓰는 것은 `App`과 화면 파일들뿐이고, 나머지는 모두 이름으로 내보냅니다.

## 기다려야 하는 일, Promise와 async/await {#ch3-async}

지금까지의 코드는 윗줄이 끝나면 곧바로 아랫줄로 갔습니다. 서버에 공지 목록을 요청하는 일은 다릅니다. 응답이 0.1초 만에 올 수도, 3초 뒤에 올 수도 있습니다. 그동안 화면이 얼어붙어서는 안 됩니다.

은행은 이 문제를 번호표로 풉니다. 창구가 바쁘면 손님을 세워 두지 않고 번호표를 줍니다. 손님은 자리에 앉아 다른 일을 하다가 번호가 불리면 창구로 갑니다. 자바스크립트의 번호표가 @@**Promise**|Promise@@(프로미스)입니다. 시간이 걸리는 함수는 결과 대신 Promise를 먼저 돌려줍니다. "지금은 값이 없지만 준비되면 주겠다"는 약속입니다. `await`는 번호가 불릴 때까지 기다렸다가 결과를 받는 일입니다.

```ts src="src/api/http.ts:87-90"
  get: async <T>(url: string, config?: ApiRequestConfig): Promise<T> => {
    const res = await http.get<ApiResponse<T>>(url, config);
    return unwrap(res.data, config);
  },
```

서버에서 자료를 읽어 올 때 화면들이 함께 쓰는 함수입니다. 꺾쇠 `< >`와 콜론 뒤는 타입 표기이니 걷어 내고 읽으면 `get: async (url, config) => { … }`입니다. `get`이라는 속성에 화살표 함수를 담았습니다. 앞에 붙은 @@`async`|async/await@@는 이 함수 안에서 `await`를 쓰겠다는 표시입니다.

88행의 `http.get(…)`은 서버에 요청을 보내고 Promise를 돌려줍니다. 그 앞의 `await`가 응답이 올 때까지 이 함수를 멈춰 세웁니다. 응답이 오면 그것을 `res`에 담고 89행으로 내려갑니다. *`await`가 붙은 줄의 아랫줄은 결과가 온 뒤에 실행됩니다.* 멈추는 것은 이 함수뿐이고 화면의 다른 일은 계속 돌아갑니다. `async` 함수를 부른 쪽도 결과 대신 Promise를 받습니다. 87행의 `Promise<T>`가 그 표기입니다. 이 함수는 [[#ch12]]에서 다시 읽습니다.

기다리던 일이 실패할 수도 있습니다. 서버가 꺼져 있으면 응답 대신 오류가 옵니다. 그래서 실패할 수 있는 일은 `try { … }`로 감싸고, 실패했을 때 할 일을 바로 뒤의 `catch (e) { … }`에 적습니다. `try` 안에서 오류가 나면 남은 줄을 건너뛰고 `catch`로 넘어갑니다. 괄호 안의 `e`에 오류가 담겨 옵니다. `src/stores/useAuthStore.ts` 49~55행이 이 모양입니다. 백엔드 서버가 꺼져 있을 때 뜬다고 1장에서 말한 "사용자 정보를 확인할 수 없습니다" 화면이 그 `catch`에서 시작됩니다.

::: note 이런 것도 가끔 나온다
이 장에서 다루지 않은 문법도 소스에 조금씩 있습니다. 값과 함수를 한 틀로 묶는 `class`는 `src/api/errors.ts`에, 글자의 모양을 찾는 정규식 `/\D/g`는 `src/utils/format.ts`에 있습니다. 겹치지 않는 값의 모음인 `Set`은 `src/hooks/useHolidays.tsx`에 나옵니다. 일정한 간격으로 일을 되풀이하는 `setInterval`은 `src/hooks/useAutoRefresh.ts`에 있습니다. 만나면 그때 찾아보면 됩니다.
:::

::: summary
- 값에는 `const`로 이름을 붙인다. 문자열에 값을 끼울 때는 백틱과 `${ }`를 쓴다.
- 함수는 값을 받아 값을 돌려준다. 우리 소스의 함수는 거의 다 `(매개변수) => 반환값` 꼴의 화살표 함수다.
- 객체는 이름 붙은 값의 묶음이고 배열은 순서 있는 묶음이다. 구조 분해로 꺼내고 전개 연산자로 새것을 만든다.
- `? :`는 둘 중 하나를, `||`와 `??`는 없을 때 대신할 값을 고른다. `&&`는 있을 때만, `?.`은 없으면 멈춘다.
- `map`과 `filter`는 콜백을 받아 새 배열을 돌려준다. 원래 배열은 바뀌지 않는다.
- 파일은 `export`로 내보내고 `import`로 가져온다. `await`는 Promise의 결과가 올 때까지 기다린다.
:::

::: quiz
1. `prev`가 `{ keyword: '점검', page: 1, size: 20 }`일 때 `{ ...prev, page: 2 }`의 `page`는 2입니다. 순서를 바꿔 `{ page: 2, ...prev }`라고 쓰면 `page`는 얼마가 됩니까? 까닭은?
2. 조회수 `visit`이 0인 공지를 `visit || '-'`로 그리면 화면에 무엇이 찍힙니까? 0이 그대로 찍히게 하려면 어떻게 고칩니까?
3. `src/utils/format.ts` 65~68행의 `fmtOffice`를 열어 읽어 보세요. `fmtOffice('100001', null)`은 무엇을 돌려줍니까? 몇 행에서 정해집니까?
:::
::: answer
1. 1이 된다. 같은 이름이 두 번 나오면 뒤에 적은 쪽이 남는데, 이번에는 `...prev`가 뒤에 있어 `prev`의 `page: 1`이 덮어쓴다.
2. '-'가 찍힌다. `||`는 0을 거짓으로 치기 때문이다. `visit ?? '-'`로 고치면 0이 그대로 찍힌다.
3. `'[100001]'`. 사무소 코드가 있으니 66행을 지나고, 67행의 삼항 연산자에서 `kanm`이 `null`이라 `:` 뒤쪽을 고른다.
:::
