반입 항목 제외 검토 결과

ATMS 개발서버(nbatmsltws01) · 작성일 2026-10-08
비교 대상: 내 검토(저장소 반입 문서 전체) + 동료 검토서 「01 프로그램 버전과 설치 요청」
  1. 이번에 새로 반입할 것은 Gitea 이미지, Jenkins 이미지(현업 제작), 배포킷 세 가지와 체크섬 파일뿐이다.
  2. 동료 검토서 12개 항목 중 반입이 필요한 것은 Jenkins 2.580.1 하나이며 버전도 일치한다. 나머지는 이미 있거나, 다른 반입물에 포함되거나, 기존 은행 제품이다.
  3. 버전이 다른 항목(Node·React·Vite)은 업체 소스에 고정된 버전을 유지한다. 새 프로젝트가 아니라 기존 소스를 그대로 빌드하는 작업이며, 검토서도 "기존 서비스는 package-lock 기준"으로 정하고 있다.
  4. 임시 실행용 이미지 등은 JEUS 의 Jakarta(Spring Boot 3) 지원 여부를 확인할 때까지 보류한다.

1. 동료 검토서에서 빠질 항목 12개 중 Jenkins 를 제외한 11개

항목검토서실제 기준빠지는 이유
Node.jsLTS 24.21.022.23.x업체 소스·빌드가 Node 22 기준(업체 Dockerfile node:22). Vite 7 의 요구(22.12 이상)를 충족하고 2027-04 까지 보안 지원. 24 로 바꾸면 업체 빌드 환경과 달라져 재검증 필요. Jenkins 이미지에 포함되고 PC 는 22.23.2 기반입
Node 20EOL, 선택 안 함사용 안 함검토서와 같은 의견
npmNode 동봉Node 22 동봉별도 반입 없음 (검토서와 같은 의견)
React19.3.019.2.4 (lock)설치 프로그램이 아니라 앱 소스의 라이브러리. 기반입한 오프라인 npm 캐시로 npm ci 하면 package-lock 에 적힌 버전이 설치됨
Vite8.3 계열7.3.1 (lock)React 와 같은 이유. "최초 install 후 lock 생성"은 새 프로젝트 기준이고 우리는 lock 이 이미 있음. 8 은 메이저 업그레이드라 설정·플러그인 수정 필요
Jenkins JVMJava 21 / 25Java 21Jenkins 이미지(2.580.1-lts-jdk21)에 JDK 21 내장. 소스 빌드 기준(Java 21)·JEUS 실행 JDK(21)와 맞춤. 별도 에이전트 없이 Jenkins 본체 1대만 사용
Python3.12 계열 권장별도 불필요빌드에 쓰지 않음. 서버 스크립트는 unzip 이 없을 때만 python3 표준 기능으로 압축을 풂. RHEL 9 는 dnf 가 Python 으로 동작해 python3 가 기본 설치돼 있음
Git CLI (서버)2.x이미지에 포함서버 호스트에서는 git 을 직접 쓰지 않음. Jenkins·Gitea 이미지 안에 git 포함. 개발 PC 의 Git for Windows 만 확인 대상
WebtoB · JEUS · Oracle현장 버전 미제공기설치 은행 제품반입 대상이 아님. 버전·명세만 담당자에게 확인 (JEUS 는 servlet 규격 확인이 핵심, 5장). JDBC 드라이버는 앱 WAR 에 포함

2. 내 검토(저장소 문서)에서 빠질 항목

항목상태빠지는 이유
Docker 엔진 (docker-29.8.0.tgz 의 dockerd·containerd 등)기반입설치에 root 가 필요하고 데몬이 상시 root 로 동작 → 1일 root 권한이 끝나면 관리 불가. 서버에 기설치된 Podman(일반 계정 실행)을 사용
Docker Desktop 설치 파일기반입Windows PC 전용. 서버와 무관
eclipse-temurin:21-jdk 이미지업체 구성백엔드 빌드는 Jenkins 이미지 안의 JDK 21 로 수행
node:22-alpine 이미지업체 구성Node 22 가 Jenkins 이미지에 포함
Kafka · Elasticsearch · Kibana 이미지업체 구성저널 스트리밍 기능은 기본 꺼짐이고 업체 시연 환경 전용 (약 2GB 절감)
Oracle DB 이미지—은행 DB(NBATMSTP) 사용
업체 Jenkins 구성 (Jenkins_v1.1.zip, 업체 플러그인 목록)기반입GitLab·GitHub·Slack·인터넷 연결 전제. 외부 연동 플러그인(GitLab, GitHub, Slack, Blue Ocean 등)을 빼고 사내 Gitea 연동 기준 16개로 재구성한 은행용 이미지로 대체
pnpm 오프라인 패키지기반입프로젝트는 npm(package-lock.json)을 사용하며 pnpm 은 쓰지 않음
