# 13. PDF 정본 ↔ ERD/AS-IS분석 대조표

> 목적: PDF(ATMS Table 1, 588건) 테이블명을 `NH AS-IS 테이블 분석.md`(ERD+PDF 96개, **컬럼 보유**)와
> 대조하여 **컬럼을 즉시 확보할 수 있는 테이블 / 신규 설계가 필요한 테이블**을 구분.
> 데이터: [13_PDF정본_ERD_대조표.csv](13_PDF정본_ERD_대조표.csv) (엑셀용, UTF-8 BOM)
> 작성일: 2026-06-02

---

## 0. 핵심 결론

1. **PDF의 `자동화기기_` 거래계열은 거의 전부 ERD 96개에 컬럼까지 존재** → 컬럼 즉시 확보.
2. **`ILM_` 계열은 거래계열의 통계/장기보관 사본** → 원본(`자동화기기_`)의 컬럼을 공유.
3. **`자동화기기관리_` 관리계열(시재/SLA/현송/평가)은 ERD에 없음** → **신규 설계 대상** (요건확정 후).
4. 사용자 직접 발견(소름 포인트): `전자화폐`·`등록금`·`방카슈랑스`·`TB_TONG_ATM_RESOURCE`·`CPC자료집계`
   → 전부 ERD에 컬럼 존재 확인. ★표시.

## 3. 신규설계(N) — 요건확정 후 (주요)

> ERD에 없는 `자동화기기관리_` 관리/운영계열. 화면 캡쳐로 컬럼 후보를 잡되, 투입 후 요건확정 필요.

- **시재**: ATM시재(운영/관리/이력), STM호퍼현황, 코너별잔여시재
- **SLA/평가**: 용역사_SLA_평가, 코너_SLA_평가, 코너평가, 평가_기준_타입_1~4 → V1.3.0 8종이 대응
- **현송**: 정규현송계획서, 추가현송보고서(실시간/집계), 현송_계획_통계, TB_SCRT_SCHEDULE
- **용역료**: 용역료_기준, 기기별/코너별_용역료산정, 기타가감용역료 → 일부 V1.3.0 대응
- **감시**: BASEFRAME서비스/인스턴스상태, BMS통신상태정보, 서버상태(감시)
- **인수도**: 인수도요청 Queue, 인수도_DATA(거래계열엔 컬럼 있음)
