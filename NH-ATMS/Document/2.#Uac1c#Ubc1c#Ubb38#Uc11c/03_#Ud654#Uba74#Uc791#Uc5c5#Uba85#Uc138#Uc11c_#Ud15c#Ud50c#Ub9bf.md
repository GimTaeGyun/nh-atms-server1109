# 화면별 작업 명세서 템플릿

> 최종 수정: 2026-04-01  
> 프리랜서에게 화면 단위로 작업 배분할 때 이 템플릿을 복사해서 사용

---

## 사용 방법

1. 이 템플릿을 복사하여 `WS_{도메인}_{화면ID}_{화면명}.md` 파일로 생성
2. 각 항목을 해당 화면에 맞게 채움
3. 프리랜서에게 전달 시: 이 명세서 + 코딩컨벤션 + API스펙 함께 전달

**파일명 예시:**
- `WS_CASH_001_거래내역조회.md`
- `WS_FAULT_001_기기장애관리.md`
- `WS_DEV_001_기기정보조회.md`

## 4. API 연동

### 4.1 목록 조회

```
GET /api/{도메인}/{기능}/list
```

**요청 파라미터:**

| 파라미터 | 타입 | 필수 | 설명 |
|---------|------|------|------|
| startDate | String | Y | 시작일 (yyyyMMdd) |
| endDate | String | Y | 종료일 (yyyyMMdd) |
| branchCode | String | N | 사무소 코드 |
| deviceId | String | N | 기기번호 |
| page | int | N | 페이지 (기본 1) |
| size | int | N | 건수 (기본 20) |

**응답:**

```json
{
    "success": true,
    "code": "200",
    "message": "성공",
    "data": {
        "list": [
            {
                "rowNum": 1,
                "transDate": "20260401120000",
                "branchName": "서울지점",
                "deviceId": "ATM0001",
                "transType": "입금",
                "amount": 500000,
                "result": "성공"
            }
        ],
        "totalCount": 150,
        "page": 1,
        "size": 20
    }
}
```

### 4.2 상세 조회 (있는 경우)

```
GET /api/{도메인}/{기능}/{id}
```
