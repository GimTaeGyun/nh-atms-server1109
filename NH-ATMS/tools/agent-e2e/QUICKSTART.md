# NH-ATMS 저널 테스트 — 5분 QUICKSTART

처음 오신 분을 위한 가장 쉬운 저널 테스트 가이드입니다.
**agent 설치·빌드 없이**, PowerShell 한 줄로 가상 거래 저널을 서버에 보내고 Kibana 에서 확인합니다.

---

## 이게 뭔가요?

ATM 이 거래할 때마다 만드는 **전자저널**을 흉내낸 가상 데이터를, 우리 서버(atms-journal)에 보내는 도구입니다.
서버가 저널을 받아 → DB에 저장 → 화면(Kibana)에 실시간으로 보여주는 전체 흐름을 눈으로 볼 수 있습니다.

```
[이 스크립트] --가상 저널--> [atms-journal 서버] --> [Oracle DB] --> [Kibana 대시보드]
```

---

## 준비물

- Windows PowerShell (기본 설치됨)
- 서버가 켜져 있을 것 (배포서버 `http://192.168.28.21:19082`, 또는 로컬 실행)

> 서버가 켜졌는지 확인:
> ```powershell

> `{"succ":true...}` 가 나오면 준비 완료.

## 원하는 값으로 저널 만들기

은행·금액·고객명·권종을 직접 지정할 수 있습니다. (생략하면 랜덤 가상값)

```powershell
# 신한은행(088), 30만원, 김철수 고객의 출금 거래
.\Send-TestJournal.ps1 -Kind 71 -Bank 088 -Amount 300000 -Name 김철수

# 여러 유형(거래·장애·시재·마감) 섞어서 50건 — 대시보드가 풍성해짐
.\Send-TestJournal.ps1 -Kind mix -Count 50

# 거래 저널 100건 (각각 랜덤 은행/금액/고객)
.\Send-TestJournal.ps1 -Kind 71 -Count 100
```

### 옵션 정리

| 옵션 | 설명 | 예시 |
|---|---|---|
| `-Kind` | 저널 유형 | `71`(거래) `21`(상태) `22`(장애) `31`(마감) `41`(시재) `11`(AP시작) `12`(개국) `mix`(혼합) |
| `-Count` | 보낼 건수 | `-Count 50` |
| `-Bank` | 은행코드 3자리 | `011`농협 `004`국민 `088`신한 `020`우리 `081`하나 `090`카카오 |
| `-Amount` | 거래금액(원) | `-Amount 500000` |
| `-Name` | 고객명 | `-Name 홍길동` |
| `-Denom` | 권종 | `50000` `10000` `5000` `1000` |
| `-WithReceipt` | 명세표 포함 | (플래그) |
| `-Server` | 서버 주소 | 로컬이면 `http://127.0.0.1:8081` |

## 2. 결과 확인 (Kibana 대시보드)

브라우저에서 열기:

**대시보드** → http://192.168.28.21:19601/app/dashboards#/view/nhatms-journal-dashboard

- **총 수신 건수** / **유입 추이**(시간별) / **유형 분포**(도넛) / **기기별 Top**
- 우측 상단 시간범위를 "Last 15 minutes" 로 두고 자동 새로고침(10초) 하면 방금 보낸 저널이 실시간으로 쌓입니다.

**개별 저널 내용 보기** → http://192.168.28.21:19601/app/discover
- 데이터뷰 `ATMS Journal` 선택 → 저널 하나를 펼치면 은행/금액/고객명/권종 등 파싱된 필드가 보입니다.

## 부하 테스트 (많은 기기 동시 시뮬레이션)

기기 여러 대가 동시에 저널을 보내는 상황(피크)을 테스트하려면:

```powershell
# 550대 × 10건 = 5,500건 동시 전송 (5,500대 피크 상황)
.\Invoke-JournalLoad.ps1 -Server http://192.168.28.21:19082 -Devices 550 -PerDevice 10 -Parallel 32
```

`TPS`(초당 처리 건수)가 결과에 표시됩니다. (참고: 5,500대 피크 기준 100~300건/초)

## 안 될 때

| 증상 | 원인 / 해결 |
|---|---|
| `실패 1` + HTTP 500 | 서버가 안 떴거나 DB 미연결. 서버 로그 확인 |
| `실패 1` + `##emsg##` | 서버가 배포됐지만 이미지 폴더 권한 등 문제 — README 참고 |
| 연결 안 됨 | 서버 주소/포트 확인 (`-Server`), 서버 컨테이너 상태 `docker ps` |
| Kibana 에 안 보임 | 시간범위 확인(방금=Last 15 min), 데이터뷰 `ATMS Journal` 선택했는지 |
